# 语界精读

<p align="center">
  <img src="assets/brand/yujie-logo-512.png" width="112" alt="语界精读 Logo">
</p>

语界精读是一款面向语言学习者的 Windows 精读工具。粘贴英文文章后，软件会根据学生年级与词汇规则标注单词，并生成适合阅读、打印和分享的排版预览。

官网：[zkmaojack.github.io/cijing-reader](https://zkmaojack.github.io/cijing-reader/)

## 功能

- 软件界面支持与目标翻译相同的近 100 种全球语言，可随时切换
- 98 种软件界面语言全部内置，可离线即时切换，不会在运行时下载语言包
- 按学生年级识别和标注生词
- 可选择近 100 种目标语言，覆盖主要世界语种
- 支持美式 IPA、英式近似 IPA、通用 IPA、易读拉丁转写、音节重音和关闭注音
- 各种注音方式均可实际显示；简体中文释义与注音支持离线生成
- 内置自动多语翻译，不提供用户 API 或网络词库配置，无需填写接口地址、模型或密钥
- 其他目标语言首次生成时需要联网，生成结果会随草稿缓存；内置分层翻译会在服务限流时切换备用路径，失败时绝不会把中文释义冒充为所选目标语言
- 支持自定义词表和标注规则
- 内置离线词典，可在无网络环境下使用
- 实时预览并导出 DOCX / PDF
- 支持浅色与深色主题
- 自动适配不同屏幕分辨率、系统缩放比例和窗口大小
- 支持预览缩放、放大查看、文章输入框调高和桌面三栏拖拽调宽
- 支持撤销重做、查找替换、格式清理、英文规范和实时阅读统计
- 自动保存草稿并保留最近 20 个历史版本
- 支持选词词典、音标释义、重点词/忽略词、多色高亮和批量词汇管理
- 支持句子语法、句型、长难句解析，以及段落教师批注和学习提示

## 下载

Windows 用户可前往 [Releases](https://github.com/zkmaojack/cijing-reader/releases/latest) 下载最新的 EXE 文件。

软件为便携版，无需安装。双击 EXE 后会直接在软件窗口中显示操作界面，不会打开浏览器。

> 软件内嵌界面使用 Microsoft Edge WebView2（Windows 10/11 通常已内置）；DOCX
> 可直接离线生成，导出 PDF 需要电脑上已安装 Microsoft Edge 或 Google Chrome。

## 从源码构建

请先安装最新稳定版 Rust，然后在项目目录运行：

```powershell
cargo build --release
```

构建产物位于：

```text
target/release/yujie-reader.exe
```

## 使用说明

1. 双击运行 EXE。
2. 粘贴需要精读的英文文章。
3. 选择软件界面语言、学生年级、目标翻译语言和注音方式；全部软件界面语言均可离线即时切换。
4. 简体中文释义与注音会直接离线生成；选择其他目标语言时，首次生成请保持联网。
5. 如有需要，可补充自定义词汇和标注；自动生成的多语翻译会随草稿缓存。
6. 在右侧查看预览，并下载 DOCX 或 PDF。

开发调试时如需使用浏览器界面，可通过命令行传入 `--browser`；使用
`--no-open` 可仅启动本地服务而不自动打开界面。
