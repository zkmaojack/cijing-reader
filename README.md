# 词境精读

词境精读是一款面向英语学习者的 Windows 精读工具。粘贴英文文章后，软件会根据学生年级与词汇规则标注单词，并生成适合阅读、打印和分享的排版预览。

## 功能

- 按学生年级识别和标注生词
- 显示音标与中文释义
- 支持自定义词表和标注规则
- 内置离线词典，可在无网络环境下使用
- 可选接入 OpenAI 兼容接口或在线词典
- 实时预览并导出 DOCX / PDF
- 支持浅色与深色主题
- 自动适配不同屏幕分辨率、系统缩放比例和窗口大小
- 支持预览缩放、放大查看、文章输入框调高和桌面三栏拖拽调宽
- 支持撤销重做、查找替换、格式清理、英文规范和实时阅读统计
- 自动保存草稿并保留最近 20 个历史版本
- 支持选词词典、音标释义、重点词/忽略词、多色高亮和批量词汇管理
- 支持句子语法、句型、长难句解析，以及段落教师批注和学习提示

## 下载

Windows 用户可前往 [Releases](https://github.com/zkmaojack/cijing-reader/releases/latest) 下载最新的 EXE 文件。

软件为便携版，无需安装。双击 EXE 后会直接在软件窗口中显示操作界面，不会打开浏览器。

> 软件内嵌界面使用 Microsoft Edge WebView2（Windows 10/11 通常已内置）；DOCX
> 可直接离线生成，导出 PDF 需要电脑上已安装 Microsoft Edge 或 Google Chrome。

## 从源码构建

请先安装最新稳定版 Rust，然后在项目目录运行：

```powershell
cargo build --release
```

构建产物位于：

```text
target/release/rust-cijing-reader.exe
```

## 使用说明

1. 双击运行 EXE。
2. 粘贴需要精读的英文文章。
3. 选择学生年级并调整标注规则。
4. 根据需要补充自定义词汇，或启用 AI/网络增强。
5. 在右侧查看预览，并下载 DOCX 或 PDF。

API 密钥只用于当次网络请求。请仅使用自己信任的接口地址。

开发调试时如需使用浏览器界面，可通过命令行传入 `--browser`；使用
`--no-open` 可仅启动本地服务而不自动打开界面。
